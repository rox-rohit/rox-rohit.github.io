FLAGSHIP CASE STUDY - 02

Contactless Gesture-Controlled Robotic Gripper

A computer-vision and embedded-systems project that turns a hand gesture into a wireless physical action.

VISION - GESTURE - MOTION
Computer vision - Embedded roboticsResearch project

From a hand gesture to physical movement.

OpenCV and MediaPipe track 21 hand landmarks. A Python control server sends gesture commands over asynchronous WebSockets to an ESP32, which drives a 3D-printed concentric-gear gripper. The project reports command latency under 50 ms.
